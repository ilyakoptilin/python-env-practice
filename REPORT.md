## 6. Проверка групп Poetry

Команды: `poetry sync --only main`, `poetry sync --only test`, `poetry sync` (полное окружение).
Использован именно `sync`, потому что `install` не удаляет лишние пакеты и результат эксперимента был бы искажён.

| Вариант | Группы | `pytest` | `ruff` | Основной скрипт | Причина |
|---|---|---|---|---|---|
| 1 | только `main` | нет (`Command not found`) | нет | запускается, импорты работают | `test` и `dev` не установлены, а сам скрипт использует только `main` |
| 2 | только `test` | да (9.1.1) | нет | не запускается: `ModuleNotFoundError: matplotlib` | `main` удалена (`sync` убрал 16 пакетов), а `pytest` остался |
| 3 | все | да | да (0.16.9) | запускается, `1 passed` | установлены все группы |

Дополнительное наблюдение по варианту 2: `pytest` установлен, но запуск тестов завершается ошибкой на этапе сбора
(`ERROR tests/test_dataframe.py`), потому что тест импортирует `plt_temp`, а тот импортирует `pandas`
из `main`. Группа `test` сама по себе не самодостаточна: тестируемый код требует основных зависимостей.
После эксперимента полное окружение восстановлено (`poetry sync`).

## 7. Точечное обновление зависимости

Выбрана `pandas`. Диапазон изменён с `>=3.0.6,<4.0.0` на `>=3.0,<4.0`
(все совместимые обновления разрешены, мажорная версия 4 запрещена). Команда: `poetry update pandas`.

- `poetry show --outdated` до обновления вернул пустой список: зависимости были только что разрешены.
- **Ограничение** прямой зависимости изменилось (`pyproject.toml`, 1 строка).
- **Установленная версия** не изменилась: `3.0.6`, более новой версии внутри диапазона нет.
- **Транзитивные зависимости** не изменились. В `poetry.lock` поменялась одна строка, `content-hash`,
  потому что хеш считается от содержимого `pyproject.toml` и должен совпадать с ним (`poetry check` → `All set!`).
- Отсутствие новой версии не ошибка: обновление выполнено корректно и результат зафиксирован коммитом.

**Почему нельзя выходить за диапазон.** Следующая мажорная версия может ломать API: код, написанный под
`pandas 3.x`, может перестать работать на `4.x`. Верхняя граница `<4.0` даёт получать исправления и
совместимые улучшения без риска неожиданной поломки. Расширять границу нужно осознанно, после проверки кода и тестов.

## 8. Чистое восстановление Poetry-проекта

1. `poetry export --format requirements.txt --output requirements.txt`: в файл попали пакеты группы `main` с хешами
   и маркерами окружения (`python_version == "3.12"`).
2. `rm -rf .venv` (плюс кэши и сгенерированные файлы), больше ничего не трогалось.
3. `poetry install` создал новое `.venv` (Python 3.12.3) и поставил 22 пакета точно по `poetry.lock`.
   Ручных `poetry add` не потребовалось.
4. `poetry run pytest` → `1 passed`.
5. Скрипт создал `temperature_24h.csv` (24 строки данных, столбцы `time,temperature_c`) и `temperature_24h.png`.

## 9. Сравнение `venv + pip` и Poetry

| | venv + pip | Poetry |
|---|---|---|
| Что обеспечивает воспроизводимость | `requirements.txt` от `pip freeze`: снимок точных версий *всех* пакетов окружения | `poetry.lock`: точное решение, полученное из `pyproject.toml`, с хешами файлов и маркерами |
| Намерение разработчика | не видно: прямые и транзитивные пакеты перемешаны | явно в `pyproject.toml`: прямые зависимости, диапазоны, группы |
| Обновление | вручную: переустановка и новый `freeze` | `poetry update <пакет>` в рамках диапазона |
| Разделение test/dev/main | нет встроенной модели (нужны отдельные файлы) | группы, `--only` / `--without` |
| Версия Python | не записывается | `requires-python` |

В обоих случаях воспроизводимость подтверждается не наличием файла, а чистой пересборкой окружения и успешным запуском.

## Ограничение проверки

Работа выполнялась в песочнице, из которой `api.open-meteo.com` недоступен (прокси отвечает `403`).
Поэтому:

- реальный запрос к API отсюда выполнить не удалось; исходный скрипт при этом падал с `JSONDecodeError`,
  а доработанный падает с понятным `HTTPError: 403`, то есть ошибка HTTP больше не маскируется;
- запуски скриптов, дающие CSV и PNG, выполнялись с подменой `requests.get` внешним запускателем
  (синтетические 168 значений в формате Open-Meteo). Он не входит в сдаваемые файлы;
- unit-тест сети не использует вовсе, на него ограничение не влияет.

Запуск на машине с доступом в интернет: `poetry run python plt_temp.py` (и `python plt_temp.py` в `pip_project`).
